# lidercontracts.com

Site do **Lider Contracts**, o produto que transforma um áudio no WhatsApp
em contrato e invoice em inglês, para prestador de serviço nos Estados
Unidos.

Publicado pelo GitHub Pages a partir do branch `main`, na raiz, em
**https://lidercontracts.com**.

## O que tem aqui

Esta pasta é a **saída do build**, não a fonte. A fonte fica no projeto
`lider-contracts` (com os arquivos comentados, o `textos.py` com o copy
nas três línguas e o `gerar-tudo.py`), e cada leva é gerada lá e enviada
para cá inteira.

```
index.html      português
en/index.html   inglês
es/index.html   espanhol
assets/         estilo, scripts, marca e favicon
CNAME           o domínio, para o GitHub Pages
sitemap.xml     as três páginas, declaradas como traduções uma da outra
robots.txt      barra os robôs que raspam para treinar
llms.txt        a apresentação do produto para as IAs de busca
404.html        manda a pessoa para a língua dela
```

**Não edite arquivo direto aqui.** O que está nesta pasta é gerado: uma
alteração feita à mão some no próximo build, sem avisar.
